# HomeStock Engine

Motore separato di HomeStock 2.0 per Home Assistant OS.

Questa app/add-on viene introdotta in modo graduale: l'inventario e le conferme rimangono nell'integrazione `food_scanner`, mentre le elaborazioni pesanti vengono migrate qui una alla volta.

## Alpha 1

- Health check
- Diagnostica
- Persistenza configurazione add-on
- Ingress Home Assistant
- Contratto capabilities per la futura integrazione

Non modifica direttamente l'inventario HomeStock.
